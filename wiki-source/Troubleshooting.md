# Troubleshooting

Check the VPK installation and the original game folder before reinstalling.

## Common problems

| Symptom | First check |
|---|---|
| App is not in LiveArea | Confirm the VPK/folder installation completed |
| App opens but content is missing | Check for `ux0:/app/RNPYSS001/game/` |
| Content folder is beside the title directory | Move `game/` inside the title directory |
| The extracted VPK folder was installed incorrectly | Repeat VitaShell → TRIANGLE → More → Install folder |
| Text feels slow in some scenes | Record the exact scene and device state; do not assume overclocking will fully fix it |

## Report a problem

Include:

- Vita model and firmware, if known.
- Port build/version.
- The exact install path.
- Whether the original `game/` folder was copied.
- Steps to reproduce and complete error text.

Do not attach copyrighted game data or unrelated personal files.
