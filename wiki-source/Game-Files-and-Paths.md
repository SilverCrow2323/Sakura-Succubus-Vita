# Game files and paths

The Vita application package and the original PC game content are separate parts of the installation.

## Expected destination

Copy the original game's `game/` folder to:

```
ux0:/app/RNPYSS001/game/
```

- Keep the title directory name exactly as documented.
- Put `game/` inside the title directory, not alongside it.
- Do not rename the `game` folder.
- Do not flatten its contents into the title directory.

## Obtain the original content

Use the original game's official source: [Sakura Succubus Vita source](https://store.steampowered.com/app/1202310/Sakura_Succubus).

> [!IMPORTANT]
> **MUST KNOW!!** Do not commit the original game's proprietary files to this repository or attach them to public issues. Share paths, logs and reproducible observations instead.
